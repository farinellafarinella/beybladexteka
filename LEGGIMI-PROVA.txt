GITHUB
Estrai lo ZIP e carica TUTTO IL CONTENUTO nella radice del repository.
index.html deve essere nella radice, non dentro una cartella aggiuntiva.
Conserva la cartella emulator e tutte le sottocartelle.
Non caricare lo ZIP come unico file. Non servono npm o compilazione.
GitHub Pages: main, cartella / (root).
I file sono meno di 100. Il catalogo è incluso in catalog.json;
le immagini arrivano tramite link diretti e richiedono Internet.

GBA
Scegli il tuo file .gba dall'emulatore oppure inseriscilo come
emulator/roms/beyblade.gba. La ROM non è inclusa.

I tornei online, la classifica condivisa e i premi evento non sono attivi
nella prova. Le altre sezioni ancora da convertire sono indicate sul sito.
